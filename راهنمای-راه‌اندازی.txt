دستیار هوشمند ترید — بسته توسعه نسخه ۲

مهم:
- فایل‌های این بسته سورس یک PWA و سرویس پشتیبان اسکن هستند؛ برنامه هنوز روی اینترنت عمومی میزبانی نشده و APK نیست.
- اسکنر از APIهای عمومی وب‌سایت تبدیل استفاده می‌کند (غیررسمی و ممکن است تغییر کنند).
- این APIها داده بازار عمومی/اسپات هستند. هنوز اثبات نشده فهرست نمادها و قیمت دقیقاً با «اهرم حرفه‌ای» یکسان باشد. به همین دلیل خروجی را سیگنال معاملاتی قطعی تلقی نکنید.
- نسخه فعلی تحلیل ۱ساعته انجام می‌دهد. گام بعدی باید تأیید قراردادهای اهرمی و افزودن کندل‌های ۱۵m و ۴h، دفتر سفارش، کارمزد و فاندینگ باشد.
- هیچ ورود حساب، API key، سفارش، برداشت یا دسترسی به موجودی در این کد وجود ندارد.

اجرای سرویس:
1) روی کامپیوتر/سرور Python 3.10+ نصب باشد.
2) داخل backend اجرا کنید:
   pip install -r requirements.txt
   uvicorn main:app --host 0.0.0.0 --port 8000
3) برای استفاده از گوشی، سرویس را پشت HTTPS روی هاست قرار دهید (CORS برای تست باز است؛ در استقرار واقعی محدودش کنید).
4) فایل‌های ریشه (index.html, manifest.json, sw.js) را روی هاست استاتیک HTTPS بگذارید.
5) آدرس سرور پشتیبان را در برنامه وارد کنید؛ باید /health پاسخ {"ok":true} بدهد.

نصب روی اندروید:
Chrome > نشانی سایت > منوی سه‌نقطه > Add to Home screen / Install app

احتیاط:
امتیازها صرفاً خروجی یک الگوریتم ساده غربال‌گری هستند، نه پیش‌بینی قطعی. حدضرر/هدف بر اساس ATR و قبل از اعمال کارمزد، فاندینگ، لغزش قیمت و مقررات مارجین است.
